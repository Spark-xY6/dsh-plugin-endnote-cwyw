给同一篇 Word 稿补引文，使用插件能多做什么？

在同一篇五段稿件上，两次使用插件、两次只用普通工具，四个独立的 Codex 会话都找到了正确的论文和页码，都保留了缺乏依据的句子并标明缺证。四份交付都把 190 条记录增至 192 条，在 Word 中保存了四处真实 EndNote 引文、三条文末参考文献。插件组还各把两篇新增论文的 PDF 存入了交付库，普通工具组两次都没有随库附入这两个 PDF。这个小样本能检验具体工作步骤；同一篇稿件反复成功，仍不能估计其他稿件的成功率。

外部去重数据给出另一条采用边界。直接调用插件的记录匹配规则，在卒中和血液学两套数据上自动找回了 93.1% 和 57.6% 的已标注重复对。专门做书目去重的 BibDedupe 在相同数据上分别找回 99.6% 和 83.0%。两者自动接受的记录对中都没有观测到误合并。对于希望找齐大量历史重复记录的维护者，应把下文的漏检和待复核工作量一起考虑。逐项结果

怎样复现同一篇稿件

  1. 从本机合法安装的 EndNote 21 示例中恢复 Sample_Library_21.enlx，取包含 190 条有效记录和 2 条回收站记录的这一版。建一篇独立的 Word 文档，按冻结答案中的五个英文原句逐段写入。第一段在 Wiegrebe 的蝙蝠声呐论述后，用 EndNote 原生插入 Wiegrebe（2008）的真实引文并应用 Nature 样式。本次示例库中的原始记录号是 60，复现时应核实论文身份。原句、旧文献与三处新引文的评分标准 · Wiegrebe 论文
  2. 从出版商取得三篇 PDF，将 Sandve 命名为 article-01.pdf，复制同一字节为 article-04.pdf。Wilson 为 article-02.pdf，Gorresen 为 article-03.pdf。因此四个文件只对应三篇论文，其中 Gorresen 是干扰项。稿件内容为评测专门撰写，仓库仅分发原句、标识和校验材料。重建 DOCX 时 Word 可能重新分配内部标识，应另存新副本并重新核验现有引用。Sandve · Wilson · Gorresen · 原始输入文件清单及 SHA-256
  3. 每个会话只交付 PDF 文件夹、旧库和部分已引文的稿件。将协议中的同一条英文请求发给两组，答案与其他会话输出对两组均保密。预定正确位置是随机种子句引 Sandve 物理第 3 页、整洁数据表句引 Wilson 第 5 页、绘图数据保存句再引 Sandve 第 3 页。最后一句声称一项涉及 240 家实验室的试验将耗时减少 73%；本次给出的 PDF 无此依据，应保留文字、不给引文并说明缺证。页码从 PDF 第一页算起。协议全文
  4. 评测者用副本逐段核查正文、字段中的论文身份、库中新增行、旧记录与附件，并在桌面 Word 上执行前述删除和重插。每个会话的选文与实物交付分别评分，即使只有计划，也能单独记录选文表现。重复次数为每组两次，独立稿件数为一。未对四次结果做显著性检验。

$data = Join-Path (Split-Path -Parent (Get-Location).Path) 'ldd-comparison-data'

foreach ($study in 'stroke','haematology') {
    $dir = New-Item -ItemType Directory -Path (Join-Path $data $study) -Force
    foreach ($file in 'records_pre_merged.csv','merged_record_ids.csv') {
        Invoke-WebRequest "$raw/$study/$file" -OutFile (Join-Path $dir.FullName $file)
    }
}
