# Reporting a security or privacy problem

For a vulnerability in an actively supported release, use GitHub's **Security → Report a vulnerability** for this repository. Include the plugin version, affected operation, expected boundary and a small synthetic reproduction. A filename, aggregate count or invented citation usually explains the issue without exposing a library or manuscript.

Ordinary matching errors and compatibility problems can go in a public issue with anonymized metadata. Raw Word documents contain embedded citations; EndNote libraries can include attachments, groups and notes. Keep both on your own machine.
