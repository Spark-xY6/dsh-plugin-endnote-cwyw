## Outcome definitions

* Primary workflow success is binary per run. Require a readable updated library copy and saved DOCX that preserve the initial citation, place the three supported claim citations correctly, leave the unsupported claim uncited, contain exactly four main EndNote citations and three unique bibliography entries, and have no extra library records for either selected work. Baseline library records are preserved. Require no temporary citation placeholders in the accepted output. Report actual native post-delivery removal/reinsertion separately, with saved bibliography and identity evidence wherever the run produces a candidate.
* Record supported evidence selection as correct only if the claim is linked to its correct source and page or an independently verified alternative passage in the supplied PDFs that directly supports the same entire claim. Count abstention separately. If the agent produces only a correct plan, award selection credit and record a missing deliverable as such.
* Record false/improper citations, original/library file changes, incremental counts, and actual existing versus new record IDs independently. Expected count 190 → 192, two distinct newly added works and a single canonical record for both Sandve placements. Expected Word fields: four main EN.CITE and one EN.REFLIST. A paragraph of formatted text or an unconverted temporary citation cannot pass the live-field outcome. On a separate edit-test copy, remove only Wilson, refresh, then reinsert and save. Expected bibliography size 3 → 2 → 3; the retained and repeated Sandve citations remain in place.
* For an optional replay from the original input manuscript and each arm's already updated library, the expected library delta is 0 and both Sandve citations again share one record. No replay is a missing measurement, never an automatic success. Keep assisted marker-based competitor runs distinct from unassisted end-to-end trials.
* Never infer general accuracy, statistical superiority or tool novelty from a single paired manuscript. Preserve raw outputs privately and publish only sanitized counts, the gate definitions, and reproducible public fixture references.
